# Hunar logo

The mark is an **H** whose two uprights hold a spirit-level vial, with the bubble resting at the
centre. Every trade uses a level, and it means measuring against a true standard: what Hunar does
when it helps an assessor check a worker's skill against the national standard, the same way for
everyone. Workers see a tool they know; people who read see the H.

## Colour

| Name | Hex | Use |
| --- | --- | --- |
| Neel (indigo) | `#1E2A78` | Wordmark, uprights, bubble, dark backgrounds |
| Genda (marigold) | `#F4A51C` | The vial only |
| White | `#FFFFFF` | Ground; the uprights on Neel |

White on Neel is 12.7:1 and Genda on Neel 6.2:1. Genda on white is 2.0:1, so it is never used for
text, and the bubble is always Neel, never a white hole in the marigold vial.

## Rules

* Keep clear space around the logo of at least the width of one upright on every side.
* Do not stretch, rotate, outline or recolour parts of the mark, and do not put the full-colour
  version on marigold or busy photos: use the one-colour version there.
* Below 48 px use `hunar-favicon.svg`.
* The wordmark is drawn as shapes, not typed. Text in Indian scripts uses the Baloo 2 family by
  Ek Type (SIL Open Font License), which has matching designs for Devanagari, Bengali, Gujarati,
  Gurmukhi, Kannada, Malayalam, Odia, Tamil, Telugu and Urdu. The हुनर in the bilingual lockup is
  live Baloo 2 text on the canvas; it is not yet outlined into an SVG here.
* Transliterations of the name into other scripts (canvas board "Name in Indian scripts") must be
  confirmed by a native speaker before use.
* Before registering the name or mark, run a trademark search: this design has not been checked
  against existing marks.
